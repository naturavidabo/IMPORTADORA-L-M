# L&M Importadora V1.1

Prototipo funcional local-first para validar flujo de inventario, ventas, red y solicitudes antes de conectar Supabase.

## Incluye
- Perfiles Mauro / Laura / La Paz / Sucre.
- Inventario y precios independientes por sucursal.
- Fotos pequeñas de referencia mediante cámara/archivo.
- Alta y edición de productos y variantes.
- Ajuste de stock.
- Venta con descuento automático de inventario.
- Recibo imprimible / PDF mediante el navegador.
- Red L&M con permisos de visibilidad por inventario.
- Solicitudes entre sucursales y aceptación/rechazo.
- Persistencia local mediante localStorage.

Conectar Supabase Auth, PostgreSQL, Storage y RLS para sincronización real multiusuario.
